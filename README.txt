Curious Owl website
===================

Files
  index.html      The main landing page with navigation and case studies teaser.
  portfolio.html  The dedicated portfolio page with Problem-Solution-Results case studies.
  favicon.svg     Browser tab icon.
  assets/         Images for portfolio case studies (in assets/portfolio/).

Uploading to your hosting (HostGator, which curiousowl.in points to)
  1. Log in to HostGator cPanel and open File Manager.
  2. Go to the public_html folder.
  3. Upload index.html, portfolio.html, favicon.svg, and the assets/ folder there.
  4. Open https://curiousowl.in to check.

Notes
  - Fonts load from Google Fonts, so the page needs an internet connection to look right.
  - The contact form is not connected to email yet. It tells visitors to write to
    consulting@curiousowl.in. To make it send, connect a form service such as Formspree
    and point the form at it.
